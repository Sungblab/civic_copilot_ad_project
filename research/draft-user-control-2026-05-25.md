# Draft User Control Research

연결 반복: Cycle 15 - 신고문 사용자 검토/수정 통제

## 조사 목적

Cycle 14까지는 사진, 위치, 서버/AI 데이터 보관을 최소화했다. 다음 공백은 AI가 만든 신고문 초안을 사용자가 어떻게 확인하고 수정한 뒤 공식 채널에 붙여 넣는가이다. Civic Copilot은 공식 접수 기관이 아니므로, AI 초안이 곧 최종 민원이 되는 흐름을 피하고 사용자의 사실 확인과 수정 통제를 별도 설계 요소로 둬야 한다.

## 확인한 근거

| 자료 | 확인한 사실 | 설계 반영 |
|---|---|---|
| 국민신문고 민원 이용 안내 | 민원 절차는 신청서 작성, 작성한 민원 내용과 유사한 처리사례 검토, 처리기관 선택 및 제출, 접수, 처리, 만족도 조사로 이어진다. | Civic Copilot의 신고문은 공식 제출 전 초안이며, 사용자가 사실과 채널을 확인한 뒤 공식 신청서에 옮겨야 한다. |
| 개인정보보호위원회 생성형 AI 서비스 이용자 개인정보 보호 가이드 보도자료 | 생성형 AI 이용자는 입력 정보가 어떻게 처리되는지 이해하고, 대화 기록 저장·삭제, 학습활용 거부 같은 통제 기능을 확인해야 한다. | 신고문 수정 이력은 서버에 저장하지 않고 브라우저 현재 화면에서만 편집한다. 향후 제품화 시 초안/수정본 저장 여부와 삭제 경로를 명확히 안내한다. |
| 개인정보보호위원회 개인정보 처리방침 작성지침 개정 보도자료 | 생성형 AI 부록은 사용자가 입력한 텍스트, 음성, 첨부파일과 서비스 이용 과정에서 생성된 결과물이 수집·저장되는 경우 처리항목으로 기재하고, 부적절한 답변 신고·이의 제기 방법을 포함하도록 한다. | AI 초안과 사용자가 수정한 문장이 저장되는지 여부를 UI와 보고서에 분리해서 설명한다. 부적절한 초안은 피드백 신호로 남기되 원문은 저장하지 않는다. |
| 개인정보보호위원회 AI 투명성 보도자료 | 생성형 AI 분야에서 입력정보 학습 활용 여부, 보유기간, 옵트아웃 절차는 이용자가 직관적으로 이해할 수 있어야 한다. | 결과 화면에 "초안 검토/수정" 섹션을 두고, 사용자가 수정한 최종 문장은 공식 채널로 직접 복사하는 경계만 둔다. |
| NIA 국가 인공지능 사업추진 윤리원칙 | AI 사업은 위험요인을 선제적으로 파악하고, 사회보편적 제도와 윤리규범 안에서 오남용 방지 책임을 고려해야 한다. | AI 초안은 사실을 과장하거나 확정 판단을 만들지 않도록, 사실 확인·과장 제거·개인정보 제거·최종 책임 경계를 체크리스트화한다. |

## 설계 결론

MVP에 `신고문 검토/수정 통제`를 추가한다.

1. AI가 만든 문장은 `초안`으로 표시하고, 사용자가 공식 제출 전에 수정해야 함을 안내한다.
2. 수정 전 확인 항목은 `사실 확인`, `과장 제거`, `개인정보 제거`, `공식 채널 직접 제출` 네 가지로 둔다.
3. 브라우저 편집 UI는 수정본을 서버로 보내지 않고, 다운로드/복사 리포트에만 반영한다.
4. 피드백 루프는 "보완 필요" 같은 선택 신호만 저장하고 초안 원문 또는 수정본 원문은 저장하지 않는다.
5. 향후 실제 AI 연동에서는 부적절한 초안 신고·이의 제기와 수정본 저장 여부/삭제 경로를 별도 정책으로 둔다.

## 페르소나별 관점

| 관점 | 질문 | 설계 답 |
|---|---|---|
| 대학생 시민 | AI 문장을 그대로 내도 되는지 알 수 있는가 | "초안" 라벨과 수정 체크리스트를 보여준다. |
| 디지털 취약 사용자 | 무엇을 고쳐야 하는지 쉬운 순서로 알 수 있는가 | 사실, 과장, 개인정보, 제출 채널 순서로 짧게 제시한다. |
| 외국인 주민 | 한국어 초안을 그대로 믿어도 되는지 구분되는가 | 공식 제출 전 본인이 아는 사실과 다른 표현을 지우도록 안내한다. |
| 행정 담당자 | 접수 문장이 사실 중심으로 들어오는가 | 추정, 감정, 과장 표현보다 위치·문제·요청 조치 중심으로 정리한다. |
| 안전/윤리 검토자 | AI 오남용과 개인정보 위험을 줄이는가 | 초안/수정본 저장 안 함, 부적절 초안 피드백, 사용자 최종 확인 경계를 둔다. |

## 구현 반영 기준

- Analyzer: `draftControl` 객체를 추가하고 `iteration: cycle-15`로 추적한다.
- UI: `신고문 검토/수정` 섹션, 편집 가능한 textarea, 초안으로 되돌리기 버튼, 수정본 복사 버튼을 추가한다.
- 로컬 저장: 최근 이력과 피드백에는 수정본 원문을 저장하지 않는다.
- 다운로드: 사용자가 화면에서 수정한 문장이 있으면 텍스트 리포트의 신고문에 수정본을 반영한다.
- 테스트: analyzer, UI smoke, localStorage 누출 방지, 다운로드 반영을 검증한다.
