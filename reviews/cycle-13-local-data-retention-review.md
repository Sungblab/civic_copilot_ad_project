# Cycle 13 - Local Data Retention Review

## 목적

Cycle 12 재조사에서 도출한 개인정보 보강 과제를 MVP에 반영한다. 피드백 로그뿐 아니라 최근 분석 이력도 원문 위치, 신고문, 사진을 저장하지 않도록 조정한다.

## 페르소나 리뷰

| 관점 | 검토 질문 | 반영 |
|---|---|---|
| 대학생 시민 | 발표 준비나 화면 공유 중 상세 위치가 남지 않는가 | 최근 분석에는 `서울 지역`, `지역 확인 필요`, `위치 미입력` 같은 지역 수준 라벨만 저장한다. |
| 디지털 취약 사용자 | 저장되는 정보와 삭제 방법을 쉽게 알 수 있는가 | 최근 분석 영역에 "브라우저에만 저장", "삭제하면 이 브라우저의 최근 분석만 삭제" 문구를 표시한다. |
| 외국인 주민 | 상담이나 제출 전 임시 분석이 개인정보 부담으로 남지 않는가 | 신고문 원문과 상세 주소가 최근 이력에 남지 않도록 한다. |
| 행정 담당자 | 신고 품질 개선에 필요한 최소 신호는 유지되는가 | 최근 이력은 유형, 채널, 긴급도, 지역 수준 라벨만 남겨 데모 흐름을 유지한다. |
| 안전/윤리 검토자 | Privacy by Design과 보관·파기 원칙에 맞는가 | 기존 localStorage 이력도 렌더링 시 원문 위치와 draft 필드를 제거해 정리한다. |

## 구현 반영

| 항목 | 변경 |
|---|---|
| 저장 구조 | `location` 대신 `locationLabel` 저장 |
| 지역 요약 | 서울, 부산, 대전, 대구, 인천, 광주, 울산, 세종은 광역 단위로 요약 |
| 알 수 없는 위치 | `지역 확인 필요`로 표시 |
| 위치 없음 | `위치 미입력`으로 표시 |
| 기존 이력 정리 | 이전 스키마의 `location`, `draft` 필드는 읽을 때 제거 |
| 사용자 고지 | 최근 분석은 이 브라우저에만 저장되고 삭제 버튼으로 지울 수 있음을 표시 |

## 테스트

추가한 UI smoke test는 다음을 검증한다.

1. 최근 분석 localStorage에 `location` 필드가 없다.
2. 상세 위치 문자열 `국민대학교`가 저장소나 최근 분석 UI에 노출되지 않는다.
3. `locationLabel`은 `서울 지역`으로 저장된다.
4. 로컬 저장과 삭제 범위 고지가 화면에 보인다.

## 결정

이 반복으로 MVP의 개인정보 설계는 "피드백 최소화"에서 "피드백 + 최근 이력 최소화"로 확장되었다. 이후 실제 AI 연동 단계에서는 사진 원본 보관 기간, 서버 로그 비식별화, 사용자 다운로드 리포트의 개인정보 포함 여부를 별도 반복으로 다룬다.
