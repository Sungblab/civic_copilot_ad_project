# Cycle 15 - Draft User Control Review

## 목적

AI가 생성한 신고문은 공식 민원이 아니라 사용자가 검토할 초안이다. 이번 반복은 AI 초안을 사용자가 사실 중심으로 수정하고, 수정본 원문을 서버나 로컬 이력에 저장하지 않는 흐름을 MVP와 문서에 반영한다.

참조 리서치: `research/draft-user-control-2026-05-25.md`

## 페르소나 리뷰

| 관점 | 검토 질문 | 반영 |
|---|---|---|
| 대학생 시민 | AI 문장을 그대로 제출해도 되는지 구분되는가 | `신고문 검토/수정` 섹션에 AI 초안 라벨과 편집창을 추가했다. |
| 디지털 취약 사용자 | 무엇을 고쳐야 하는지 쉬운 순서로 알 수 있는가 | 사실 확인, 과장 제거, 개인정보 제거, 공식 채널 직접 제출 4개 체크를 제공한다. |
| 외국인 주민 | 한국어 초안을 본인 상황에 맞게 고칠 수 있는가 | 편집 가능한 textarea와 초안 되돌리기 버튼을 제공한다. |
| 행정 담당자 | 접수 문장이 사실 중심으로 정리되는가 | 추정·과장보다 위치, 문제, 요청 조치 중심으로 확인하도록 안내한다. |
| 안전/윤리 검토자 | AI 초안과 사용자 수정본이 과도하게 저장되지 않는가 | 수정본 원문은 서버나 로컬 이력에 저장하지 않고 복사/다운로드에만 사용한다. |

## 구현 반영

| 항목 | 변경 |
|---|---|
| Analyzer | `draftControl` 추가, `cycle-15`로 추적 |
| UI | `신고문 검토/수정` 섹션, 편집창, 초안 되돌리기, 수정본 복사 추가 |
| 다운로드 리포트 | 사용자가 편집한 현재 문장을 `[신고문]`에 반영하고 검토 체크리스트 포함 |
| 로컬 저장 | 최근 분석 이력과 피드백에는 수정본 원문을 저장하지 않음 |
| 문서/슬라이드 | AI 초안 사용자 통제와 수정본 미저장 원칙 추가 |

## 테스트

추가한 테스트는 다음을 검증한다.

1. analyzer 결과가 `cycle-15` 신고문 검토/수정 통제를 반환한다.
2. 검토 체크리스트가 사실 확인, 과장 제거, 개인정보 제거, 공식 채널 직접 제출로 구성된다.
3. 모바일 UI에서 편집 가능한 신고문과 수정본 미저장 고지가 표시된다.
4. 사용자가 편집한 문장이 다운로드 리포트에 반영된다.
5. 편집한 신고문 원문이 localStorage의 최근 이력이나 피드백에 저장되지 않는다.

## 결정

Cycle 15 이후 Civic Copilot의 문장 생성은 "AI가 대신 작성해서 제출"이 아니라 "AI가 초안을 만들고 사용자가 검토·수정해 공식 채널에 직접 제출"하는 흐름으로 더 명확해졌다. 다음 반복은 실제 발표/보고서 관점에서 7분 안에 너무 많은 안전장치가 산만해 보이지 않도록 핵심 메시지와 슬라이드 정보 밀도를 정리하는 방향이 적합하다.
