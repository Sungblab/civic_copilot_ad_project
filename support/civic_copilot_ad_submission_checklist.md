# Civic Copilot AD 프로젝트 제출 체크리스트

## 필수 제출물

- [ ] 발표 영상: 7분 이내 녹화
- [ ] 발표자료: `civic_copilot_ad_presentation.pptx` 또는 PDF 버전
- [ ] 보고서: `civic_copilot_ad_report.docx` 또는 PDF 버전

## 제출 전 확인

- [ ] 첫 30초 안에 문제 상황이 공감되게 제시되는가?
- [ ] “기존 신고 플랫폼은 이미 있다”는 시장조사 결론이 들어가는가?
- [ ] 차별점이 “접수 전 검증·작성·라우팅”으로 명확한가?
- [ ] AI 활용이 구체적으로 설명되는가? (VLM, LLM, RAG/규칙 DB, 채널 라우터)
- [ ] 구현 가능성이 설명되는가? (스마트폰 카메라, GPS, 클라우드, AI 모델)
- [ ] 위험과 한계가 설명되는가? (AI 오판, 개인정보, 긴급상황)
- [ ] 결론 문장이 명확한가? “안전신문고를 대체하지 않고 더 잘 쓰게 만드는 신고 전 AI 보조자”

## 발표 영상 녹화 가이드

1. 발표자료를 전체 화면으로 띄운다.
2. 발표 대본을 한 번 읽고 시간을 잰다.
3. 목표 시간은 6분 30초~6분 50초로 잡는다.
4. 녹화 후 유튜브 업로드 형식이 필요한 경우, 영상 공개 범위는 수업 공지 기준에 맞춘다.
5. 제목 예시: `[소프트웨어프로젝트 I AD] Civic Copilot - 생활민원 신고 전 AI 코파일럿`

## 팀 정보 입력 위치

- PPT 1번 슬라이드: 팀명/조원 이름 입력
- 보고서 표지: 팀명/조원 이름 입력

## 선택 제출물

- 발표대본: `civic_copilot_ad_speaker_script.md`
- 개발 확장 문서: `civic_copilot_development_plan.md`는 실제 구현을 진행할 때 참고용으로 사용
