# Civic Copilot AD 제출 패키지 안내

이 패키지는 소프트웨어프로젝트 I / AD 프로젝트 제출을 위해 정리한 결과물입니다.

## 실제 제출 권장 파일

1. `civic_copilot_ad_presentation.pptx`
   - 7분 발표용 PPT
   - 1번 슬라이드의 팀명/조원 이름을 채워서 사용

2. `civic_copilot_ad_report.docx`
   - 최종 보고서
   - 표지의 팀명/조원 이름을 채워서 사용

3. 발표 영상
   - `civic_copilot_ad_speaker_script.md`를 보고 7분 이내로 녹화
   - 수업 공지 방식에 따라 YouTube 업로드

## 보조 파일

- `civic_copilot_ad_presentation.pdf`: PPT PDF 변환본
- `civic_copilot_ad_report.pdf`: 보고서 PDF 변환본
- `civic_copilot_ad_speaker_script.md`: 발표 대본
- `civic_copilot_ad_submission_checklist.md`: 제출 전 체크리스트
- `civic_copilot_development_plan.md`: 실제 개발을 진행할 때 참고할 확장 개발 문서

## 발표 핵심 문장

“Civic Copilot은 안전신문고를 대체하지 않고, 안전신문고를 더 잘 쓰게 만드는 신고 전 AI 보조자입니다.”
